# ثبت بارکد (BarcodeLog)

اپلیکیشن اندروید برای اسکن بارکد، ثبت اطلاعات گیرنده و خروجی اکسل.

## امکانات
- ساخت «فایل جدید» (هر فایل یک لیست مستقل است؛ مثلاً یک روز کاری یا یک محموله)
- اسکن همهٔ انواع بارکد و QR (EAN، UPC، Code 128، Code 39، ITF، DataMatrix، PDF417، Aztec، QR و ...) — آفلاین و بدون نیاز به Google Play Services
- فرم ثبت: بارکد، نام و نام خانوادگی (یک فیلد)، نوع بسته (فقط «بسته» یا «پاکت»)، شماره تلفن، توضیحات
- دکمهٔ «ثبت و اسکن بعدی» برای ثبت سریع چندین مورد پشت‌سرهم
- هشدار بارکد تکراری داخل یک فایل
- ویرایش و حذف رکورد (لمس = ویرایش، نگه‌داشتن = حذف)
- ذخیرهٔ محلی روی گوشی (SQLite)
- خروجی اکسل (.xlsx، راست‌به‌چپ، تاریخ شمسی) با دو دکمه:
  - **اشتراک اکسل**: ارسال مستقیم به تلگرام، واتساپ، ایمیل و ...
  - **ذخیرهٔ اکسل**: ذخیره در گوشی (دانلود، درایو و ...)

- ظاهر مدرن با فونت وزیرمتن (متن) و وزیرمتن Black (تیترها)

## ساخت APK

### روش ۱ — گیت‌هاب (بدون نصب هیچ چیز)
1. در GitHub یک مخزن (repository) جدید بسازید و همهٔ فایل‌های این پوشه را آپلود کنید (پوشهٔ `.github` هم باید باشد).
2. به تب **Actions** بروید؛ ساخت به‌طور خودکار شروع می‌شود (حدود ۳ تا ۵ دقیقه). اگر شروع نشد، workflow با نام **Build APK** را با **Run workflow** اجرا کنید.
3. پس از سبز شدن، وارد اجرا شوید و از بخش **Artifacts** فایل `BarcodeLog-apk` را دانلود کنید. داخل آن `app-debug.apk` است.

### روش ۲ — اندروید استودیو
1. پوشه را در Android Studio (نسخهٔ Koala یا جدیدتر) باز کنید و صبر کنید Gradle همگام شود.
2. از منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** استفاده کنید.
3. فایل در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

> دانلود وابستگی‌ها از سرورهای گوگل انجام می‌شود؛ اگر از ایران ساخته می‌کنید ممکن است به VPN یا Mirror نیاز باشد.

## نصب روی گوشی
فایل APK را به گوشی منتقل کنید، آن را باز کنید و در صورت پرسش، «نصب از منابع ناشناس» را برای همان برنامه (مرورگر/فایل‌منیجر) مجاز کنید. در اولین اسکن، دسترسی دوربین را تأیید کنید.

## نکات
- نسخهٔ debug با کلید آزمایشی امضا می‌شود و برای استفادهٔ شخصی/سازمانی کاملاً قابل نصب است. برای انتشار در مارکت‌ها باید نسخهٔ release با کلید اختصاصی ساخته شود.
- حداقل اندروید: ۷.۰ (API 24).
- برای روشن کردن چراغ قوه هنگام اسکن، کلید بلند/کم کردن صدا را بزنید.

## ساختار کد
| فایل | کار |
|---|---|
| `MainActivity` | فهرست فایل‌ها، ساخت/تغییر نام/حذف فایل |
| `RecordsActivity` | رکوردهای یک فایل، خروجی اکسل (اشتراک/ذخیره) |
| `RecordFormActivity` | فرم ثبت و ویرایش + اسکن |
| `Db` | پایگاه داده SQLite |
| `XlsxWriter` | ساخت فایل xlsx بدون کتابخانهٔ اضافه |
| `Jalali` | تبدیل تاریخ میلادی به شمسی |
